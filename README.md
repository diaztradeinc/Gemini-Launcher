# RAM TRX Uconnect 5 Cockpit & Navigation Interface

High-performance, minimalist digital cockpit designed specifically for the Ram 1500 TRX 12" Uconnect screen with Google NavSDK architecture, OBDLink MX+ live telemetry, and independent multi-page media suite.

## How to Build the APK in Android Studio:
1. Extract this `RamTRX_Cockpit_Android_Project.zip` archive.
2. Open **Android Studio** and click **Open** -> Select the unzipped folder.
3. Wait for Gradle sync to complete (automatically downloads required SDK components).
4. Click **Build** -> **Build Bundle(s) / APK(s)** -> **Build APK(s)**.
5. Transfer the output `app-debug.apk` to your Android unit or Uconnect AI box!
